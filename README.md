## Sobre

Página única com apresentação, habilidades, projetos e contato. Construída sem
framework nem build — HTML, CSS e JavaScript diretos, com foco em código legível
e carregamento rápido.

Paleta escura com acento laranja, tipografia Inter e layout responsivo em três
breakpoints.

Hospedado no GitHub Pages.

## Estrutura

```
index.html        marcação e conteúdo
css/style.css     estilos, com tokens em :root
js/script.js      navegação, animação de digitação e revelação ao rolar
imagem/           fotos e capturas dos projetos
```

## Rodando localmente

Não há build. Qualquer servidor estático resolve:

```bash
python3 -m http.server 8000
```

E abrir http://localhost:8000
